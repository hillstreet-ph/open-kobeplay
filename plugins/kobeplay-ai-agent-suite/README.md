# KobePlay AI Agent Suite

One portable, vendor-neutral plugin and skill package for five portal agents. It consolidates portal routing, source authority, connector governance, approvals, and influencer contract qualification without duplicating Notion records or exposing private operations.

Install through the included marketplace manifest or copy the plugin folder into a compatible skill host. Configure Notion, GitHub, Composio, Pipedream, or Open Connect separately with least-privilege OAuth or server-side credential references.

See `adapters/README.md` for ChatGPT/Codex, Claude, Grok, Open WebUI, Hermes Agent, and LobeHub usage.
